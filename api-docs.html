Endpoints

GET /api/check?url=https://github.com/owner/repo

Check a single repository's social preview status. Free

Response

{
  "success": true,
  "repo": "owner/repo",
  "name": "owner/repo",
  "description": "A GitHub project",
  "stars": 1234,
  "has_custom_og_image": false,
  "og_image_url": "https://...",
  "default_og": true
}

POST /api/generate

Generate a free OG preview image for any repo. Free

Request Body

{
  "url": "https://github.com/owner/repo"
}

Response

{
  "success": true,
  "repo": "owner/repo",
  "image_base64": "data:image/png;base64,..."
}

POST /api/batch

Check multiple repos at once. Pro (license key required) PRO

Request Body

{
  "license_key": "YOUR_LICENSE_KEY",
  "repos": ["owner/repo1", "owner/repo2"]
}

Response

{
  "success": true,
  "results": [
    {"repo": "owner/repo1", "has_custom_og_image": false, "stars": 100, ...}
  ]
}

Quick Start

Check a repo (curl)

curl "http://167.233.135.161:8081/api/check?url=https://github.com/vercel/next.js"

Generate an OG image (curl)

curl -X POST "http://167.233.135.161:8081/api/generate" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://github.com/vercel/next.js"}'

Batch check (Python, Pro license required)

import requests

resp = requests.post("http://167.233.135.161:8081/api/batch", json={
    "license_key": "YOUR_LICENSE_KEY",
    "repos": ["vercel/next.js", "tailwindlabs/tailwindcss"]
})
print(resp.json())
